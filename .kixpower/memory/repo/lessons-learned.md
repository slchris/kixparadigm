| LL-10 | 2026-09-22 | 2（收尾期）| **结论行必须与「它自己那一次运行」的逐字输出同源**：把另一次运行的读数抄进本次的结论行，会造出**没有任何门禁能察觉**的错误结论（gate 的 exit code 仍绿），且会顺着错误方向漏掉本该触发的强制规则。**判据**：报告里每个度量值都要能 `grep` 回它所属的那次运行输出块；做不到时必须显式标注「跨运行引用」并给出两次运行的 revision/窗口。**推论**：`>20% → 强制扩展 target_rules` 这类**阈值型**规则，其触发判定只认「同一次运行的读数」——用别次的 0% 去声明「未触发」是倒因为果。 | `docs/sprint-2/drift-check.md` §8 结论行 `:214`（「`ungated: 0 (0%)` → `PASS`」）vs **同节自身**逐字块 `:185`（`ungated: 15 (23.4%)`）+ `:208`（`ungated_ratio_pct: 23.4`）+ `HIGH_RISK`（无 `PASS` 行）；传播 3 处 `progress.md:55`/`:112`/`:266`；QA 在冻结 revision 复跑 = `79 / 18 / 39 / 22 (27.8%)`（两次逐字节相同）→ `qa-signoff-2.md` F-1 | observed |
